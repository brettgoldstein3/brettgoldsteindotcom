pretty clean animation-heavy launch video

- smart leading with the product immediately
- some pretty cool animations (esp the first one into the computer)
- good CTA
- script feels pretty dialed
- the music and sound fx go very well with the data/technical feel
- "start asking hard questions" is great

but
- would have done more large text to emphasize key points
- the demo in the beginning would have been more powerful with a real side by side comparison with another product.
- some lines dont match up to the visual (eg "understands business logic" should have a chart showing the logic)
- music could stop to emphasize certain things
- second cofounder popping up so shortly is a little awk
- some awk narration cuts

this is another one of the standard animation-heavy formats but with a bit more originality (probably done by a different agency).

think the biggest miss on this is just lining up the visuals and music with the narration more.

literally stopping the music + showing big text on the screen can realllly help drive a point home.
